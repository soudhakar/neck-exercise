# Neck Exercise - Brain Fog Relief 🧠

A 10-minute guided neck exercise routine designed to relieve tension, improve circulation, and clear brain fog. Works perfectly on iPhone, iPad, and desktop browsers.

## Features

✨ **What You Get:**
- 🎯 10-minute guided neck exercise routine
- 📱 Fully responsive design (iPhone, iPad, desktop)
- ⏱️ Real-time timer with progress tracking
- 💾 Automatic progress saving - resume where you left off
- 🌙 Dark mode support
- 🔇 Silent experience with visual feedback only
- 💨 No dependencies - pure HTML/CSS/JavaScript

## The Routine

The program guides you through 6 carefully selected exercises:

1. **Neck Rolls** (2 min) - Release tension and improve mobility
2. **Chin Tucks** (1.5 min) - Strengthen neck muscles and posture
3. **Lateral Neck Stretches** (2 min) - Reduce side tension
4. **Shoulder Shrugs** (1 min) - Loosen upper body
5. **Neck Rotations** (1.5 min) - Improve circulation
6. **Forward Neck Stretch** (2 min) - Final relaxation

## Troubleshooting

**Q: The timer isn't working**
A: Make sure JavaScript is enabled in your browser. Try refreshing the page.

**Q: Progress isn't saving**
A: Check if your browser allows LocalStorage. Disable private browsing mode.

**Q: Page doesn't fit on my phone**
A: Try rotating your device to landscape mode for better spacing.

**Q: Dark mode isn't working**
A: Check your system settings. Dark mode follows your device's theme preference.
